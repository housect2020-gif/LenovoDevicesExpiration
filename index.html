Fleet Warranty Check

Upload your device export. For every Lenovo serial number, this page looks up warranty status directly from Lenovo's public support site and flags anything 4+ years old — all in your browser.

No file selected
How it works: for each row, we call the same public endpoints pcsupport.lenovo.com itself uses when you type a serial into its warranty lookup box. This is unofficial (not Lenovo's partner API), so results can occasionally fail or the site can rate-limit fast repeated requests — that's what the delay setting is for. Non-Lenovo rows (VMs, etc.) are skipped automatically.
"4+ years old" is calculated from the warranty start date Lenovo returns (a reliable stand-in for ship/purchase date). If that's unavailable, we fall back to the Enrollment date column.
Click any column header to sort — click again to reverse the order.
Runs entirely client-side · nothing is stored or logged anywhere
