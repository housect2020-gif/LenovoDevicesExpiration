Fleet Warranty Check

Lenovo warranty status and device age, refreshed automatically whenever a new inventory export is uploaded to the repository.

How to refresh this report with a new inventory file
  1. Export the latest device inventory as a CSV (same columns as before).
  2. Go to this repository on GitHub, open the data folder, and click Add file → Upload files.
  3. Upload the new file and rename it exactly inventory.csv, replacing the existing one.
  4. Click Commit changes.
  5. That's it — this automatically starts the update in the background. It typically takes 45–70 minutes for ~350 devices. You can watch progress under the repository's Actions tab.
  6. Once it finishes, just refresh this page to see the new results.
